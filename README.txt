IMPORTANT:
- QR PNGs are included in qr_codes/. They point to the live URLs above.
- Upload the updated site files first. Wait until GitHub Pages has redeployed, then test all 10 links and QR codes on a phone before printing.
- Audio currently uses browser text-to-speech, not recorded MP3 files. Voice and availability can vary by device/browser. For a formal research deployment, consider using consistent recorded MP3 dialogue and testing with the target students' devices.
- This is a static site. No student data is collected or stored.

PUBLISH STEPS:
1. Open https://github.com/Caster28/acdc-english-comics
2. Open the repository and choose Add file > Upload files.
3. Upload index.html, style.css, and script.js from this folder, replacing existing files if prompted.
4. Commit changes to the main branch.
5. Open Settings > Pages and confirm the source points to main and /(root).
6. Wait for deployment, then open https://caster28.github.io/acdc-english-comics/ and test all units.
